# student-performance-prediction-using-regression
Machine Learning project to predict student math scores using regression models

## Dataset
Students Performance Dataset:
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## Models Used
- Linear Regression
- Random Forest
- Gradient Boosting

## Features
- Gender
- Parental Education
- Lunch Type
- Test Preparation Course
- Reading Score
- Writing Score
